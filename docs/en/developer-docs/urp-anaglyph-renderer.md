# URP Anaglyph Renderer Configuration (Required)

**When using Portalgraph with URP, the following configuration is required to enable anaglyph rendering.**

Select the **Universal Render Pipeline Asset** you are using (typically `Assets/Settings/URP-HighFidelity` or `Assets/Settings/PC_RPAsset`), and in the Inspector, set element 1 of the **Renderer List** to `Assets/Portalgraph/Settings/Anaglyph Universal Renderer Data`.

<figure><img src="../.gitbook/assets/image (14) (1).png" alt=""><figcaption></figcaption></figure>

You can confirm which **Universal Render Pipeline Asset** is in use by checking the **Graphics** tab in the **Project Settings**.
