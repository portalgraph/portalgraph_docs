# 3D Settings

Portalgraph supports left-right split, top-bottom split, anaglyph, and dual output 3D modes. Configure the appropriate mode for your display device.

To change the 3D mode, follow the steps below.

Press **F12** in the Portalgraph application to open the settings screen.

<figure><img src="../.gitbook/assets/image (52).png" alt=""><figcaption></figcaption></figure>

Click **"Next"** to open the calibration settings screen.

<figure><img src="../.gitbook/assets/image (55).png" alt=""><figcaption></figcaption></figure>

Select from the **3D** dropdown to change the 3D mode. The available modes are as follows:

| Label          | Description               | Options                                       |
| -------------- | ------------------------- | --------------------------------------------- |
| Side-By-Side   | Left-right split 3D       |                                               |
| Top-And-Bottom | Top-bottom split 3D       |                                               |
| Anaglyph       | Anaglyph (red-blue) 3D   | Color separation method can be selected.      |
| 2D             | 2D (no 3D)                |                                               |
| 2 outputs      | Dual output               | Select the output screen for the right eye.   |
