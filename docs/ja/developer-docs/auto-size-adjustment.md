# 自動サイズ調整

通常、Portalgraphは、スクリーンサイズを問わず、指定したサイズで現実に見えるように表示します。なので、身長170cmの人間はよっぽど大きなスクリーンでなければ表示しきれません。ですが、自動でスクリーンの縮尺を調整する機能が存在します。

PortalgraphプレハブのPortalgraphコンポーネントのAuto Screen Heightを、画面に収めたい高さに指定すると、そのサイズに収まるように自動で縮尺を調整します。身長170cmの人を表示するには、2と入力すると2mが収まるように縮尺されます。

なお、スクリーンの高さが指定されたサイズより大きかった場合は、縮尺は1倍になります。

また、Portalgraphは標準で\
1キー…縮小\
2キー…拡大\
3キー…リセット（サイズ、座標とも）\
になってますが、リセット時も自動調整された縮尺になります。
