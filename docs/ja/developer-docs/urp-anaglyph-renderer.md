# URP用アナグリフレンダラー設定（必須）

URPでPortalgraphを使用する際は、アナグリフを使用可能にするために必ず以下の設定をしてください。

使用するUniversal Render Pipeline Assetを選択し（通常はAssets/Settings/URP-HighFidelity、またはAssets/Settings/PC\_RPAsset）、インスペクターからRenderer Listの1番要素にAssets/Portalgraph/Settings/Anaglyph Universal Renderer Dataをセットする。

<figure><img src="../.gitbook/assets/image (102).png" alt=""><figcaption></figcaption></figure>

使用するUniversal Render Pipeline Assetは、Project SettingsのGraphicsタブから確認できます。
